# IronPulse Fitness Website

A responsive fitness landing page built with HTML, CSS, and JavaScript using Vite. This project focuses on establishing a baseline for website performance, accessibility, and SEO before future optimization.

## Features

- Responsive fitness landing page
- Hero section and fitness program cards
- Navigation and call-to-action sections
- Vite development and production build setup

## Technology Stack

- HTML5
- CSS3
- JavaScript
- Vite

## Getting Started

### Prerequisites

Install Node.js and npm.

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```

### Preview the production build

```bash
npm run preview
```
